================================================================================
COMMON INTERVIEW QUESTIONS & ANSWERS
================================================================================

Q: What was the most challenging part?
A: "Handling file uploads while ensuring security and performance. I had to
validate MIME types, limit file sizes, handle concurrent uploads safely, and
implement cascade deletion so files clean up when posts are deleted."

Q: How would you scale this?
A: "I'd add Redis caching, implement database read replicas, use a CDN for
files, add rate limiting, and implement background jobs for heavy operations."

Q: Why those technologies?
A: "FastAPI because it's fast and has built-in documentation. React because
it's the industry standard. PostgreSQL for data integrity. Docker for
reproducibility across environments."

Q: What would you do differently?
A: "I'd implement automated tests earlier (TDD), use Alembic for database
migrations, add API rate limiting, and implement better error logging."

✗ List technologies you didn't actually use
✗ Call it "simple" or minimize it
✗ Forget to mention both frontend and backend
✗ Claim it handles "millions of users" without proof
✗ Use outdated technologies without good reason
✗ Leave it vague - be specific
